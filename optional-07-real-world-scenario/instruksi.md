# Asesmen Kasus Nyata — Sistem Pengelolaan Pesanan Restoran

Studi kasus JavaScript untuk mengelola pesanan restoran menggunakan Array dan Object. Data pesanan mencakup ID, nama pelanggan, item, total harga, dan status. Implementasi mencakup tambah pesanan, pembaruan status, perhitungan pendapatan, dan penghapusan pesanan.
