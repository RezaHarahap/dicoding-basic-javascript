# Dicoding Basic JavaScript

Repository ini berisi kumpulan latihan dan submission dari kelas **Belajar Dasar Pemrograman JavaScript** Dicoding.

## Tentang Kelas

Kelas ini membahas dasar JavaScript untuk pengembangan aplikasi web dan back-end menggunakan Node.js, termasuk sintaks dasar, function, struktur data, modularisasi, OOP, functional programming, asynchronous process, dan code quality.

## Isi Repository

- `01-writing-comments` — latihan penulisan komentar pada JavaScript.
- `02-code-style` — latihan penerapan gaya penulisan kode yang konsisten.
- `03-writing-test` — latihan membuat pengujian JavaScript.
- `optional-04-oop` — latihan Object-Oriented Programming.
- `optional-05-recursive` — latihan fungsi rekursif seperti factorial dan fibonacci.
- `optional-06-full-coverage-testing` — latihan pengujian dengan cakupan yang lebih lengkap.
- `optional-07-real-world-scenario` — studi kasus sederhana pemrosesan pesanan.

## Teknologi

- JavaScript
- Node.js
- NPM
- Node Test Runner

## Menjalankan Latihan

Masuk ke folder latihan yang memiliki `package.json`, lalu jalankan:

```bash
npm install
npm test
```

Untuk file JavaScript biasa, jalankan dengan:

```bash
node index.js
```

atau sesuaikan dengan nama file utama di masing-masing folder.
